以 2008-05-12 为基准重建早期魔兽世界官方百科与部分官网，整理日期为 2026-10-15。

本版包含百科 52 页、已恢复的官网栏目与配套资源，以及最新的旧新闻和浏览修复。历史账号、报名和兑换页面作为静态展品保留。玩家截图图库仍缺原图与缩略图，Flash 与原站服务不可用。

下载 ZIP 并解压。需要 Python 3；Windows 双击 START_BROWSE.cmd，其他系统在解压目录运行：

```sh
python3 tools/serve_pages_preview.py --site site --port 0 --open-browser
```

在线浏览与后续进展见项目 README 和 CHANGELOG。
