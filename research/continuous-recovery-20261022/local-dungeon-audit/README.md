# Local dungeon trace audit

Read-only comparison of the existing Deadmines article/screenshots, the Four Dragons dynamic thumbnail targets, and the cached ArchiveCraft Instances/Outland bodies. Exact local paths, hashes, source timestamps, and concise source line locators are in [audit.json](audit.json). Raw HTML and cookie files are not copied into this report.

The Deadmines article and its nine original images already exist in the old site and v52. The parent acceptance receipt verifies originals and previews against preserved source entities, original site, Source16, and v52; the report records actual capture times from the Source16 manifest. The 13 Four Dragons thumbnail routes are exact missing entities; the page-relative path builder resolves to the expected route shape.

ArchiveCraft Instances lists 19 classic topics, all represented by old-site prose sections (16 main entries plus 3 minor instances). Its Outland page has five headings whose story subjects are covered by the old BC index and five detailed local XML pages. Current ArchiveCraft WP image paths are recorded as distinct modern assets; no remote image bytes were downloaded or compared. About and Disclaimer were present in the same acquisition batch but were not content-audited.
