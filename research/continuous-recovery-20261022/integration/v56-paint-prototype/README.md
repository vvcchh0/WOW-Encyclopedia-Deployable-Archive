It captured a control, `body{transform:translateZ(0)}`, and `img{transform:translateZ(0)}` in serial, fresh contexts. The parent review found the control screenshot fully rendered and identified an environment mismatch: this run was `headless:false`, while the formal harness uses `headless:true`. The CSS variants therefore do not isolate a production cause and are not acceptance evidence. Of 451 stable non-placeholder image routes, their recorded rectangle, visibility and natural dimensions did not change relative to control. The report preserves their per-page measurements and marks the matching boundary. The harness was amended after capture to retain query identity; the three pages were not rerun.
