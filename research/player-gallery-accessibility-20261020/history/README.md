# 2026-10-20 gallery availability history

`gallery-availability-table.json` and `.csv` reconcile the frozen v7 registry, the latest rest10b/r3 ledgers, and accepted local CDX receipts for all 50 galleries. The table has no public index rows. Native ssN full/thumb rows and nested preview rows are counted separately. Every gallery carries an explicit unqueried window from 2010-12-08 through the 2026-10-20 audit-date bound. Network execution was not performed.
