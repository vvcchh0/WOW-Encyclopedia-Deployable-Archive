以 2008-05-12 的官方百科存档为基准，继续保存百科与早期魔兽世界官网。

- 本轮补回 376 个图片资源地址，包括旧新闻配图、文章大图、指南插画、壁纸和静态图标。
- 修复已保存原图的页面链接，恢复文章图片放大、副本进度图及专业配方的查看。
- 在线版与本离线包同步至 v33。

下载 ZIP 后解压。安装 Python 3 的 Windows 用户可双击 `START_BROWSE.cmd`；macOS / Linux 用户可在解压目录运行：

```sh
python3 tools/serve_pages_preview.py --site site --port 0 --open-browser
```

50 个玩家截图图库的原编号图片仍有缺口。Karazhan 本轮未找到可用原图；指南预览与原图库分别展示和记录。欢迎通过 Issues 提供页面地址、缺图说明或可用存档链接。
