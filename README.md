# WOW Encyclopedia historical Pages mirror

This is an unofficial educational archive reconstruction based on 2008-05-12, not affiliated with Blizzard. It is a static GitHub Pages export under the project path; it performs no external fetching and collects no user data. The archive retains known gaps and does not claim a complete reconstruction.

The source `offline/site` and build manifest remain the frozen provenance inputs. HTML/XML pages are emitted as UTF-8 HTML variants so GitHub Pages can parse them, while binary assets are copied byte-for-byte.
