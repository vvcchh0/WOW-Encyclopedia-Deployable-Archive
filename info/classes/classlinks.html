Class Guide Links

Welcome to the player-created Class Guide main page. This page offers links to amazing class guides created by the World of Warcraft player base! In them you will find tips, strategies, and other useful class related information. Please be aware the links on this page were created by companies and individuals that are neither affiliated with nor supported by Blizzard Entertainment, and the views and opinions expressed in these guides do not necessarily reflect our own.

Druid | Hunter | Mage | Paladin | Priest | Rogue | Shaman | Warlock | Warrior

Class Link Rules

  • Page must be focused entirely on how to play one of the nine classes
  • Blizzard does not host guides; they must be hosted on your own web server
  • Site must be capable of getting traffic from our web site (estimated 1,000-20,000 hits a day)
  • Guides must contain quality information
  • Must not contain offensive content or link to offensive content
  • Advertising links must not link to sites that violate the World of Warcraft Terms of Use Agreement
  • Broken links will be removed if site is down for a long period of time
  • Blizzard reserves the rights to add/remove links at any time based on internal criteria
  • Submit guides, report broken links, or report violations here.
Note: If you have difficulty reaching EU forum links, try again later on. These links direct users over from the North American web site to the European web servers. Also, EU game servers undergo maintenance on Wednesdays. During this time you might have problems accessing their forums.
