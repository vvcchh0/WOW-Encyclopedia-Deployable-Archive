# 萨满天赋图标补充

为“Improved Fire Nova Totem”补入一张关联图标及其灰度状态，累计覆盖66项天赋、59张图片。天赋名称、说明和计算规则沿用2008年页面。

图片来自同一份[2019年TBC计算器备份](https://github.com/Vampyr7878/WoW-Talent-Caluclator-TBC/tree/2a5f39aadb1c88ded12ff6389f4f0bdc4470c2a4)。该备份将天赋命名为“Improved Fire Totems”；两级说明逐字一致，均位于萨满元素系第四层，引用 `Spell_Fire_SealOfFire`。因此此次按说明和位置补充对应，不再要求名称相同。Mage 的 Incinerate 与候选 Ignite 说明不同，继续保留缺口。

这是后期关联素材，未取得旧站原始JPEG。启用状态使用来源PNG，未启用状态通过独立SVG显示灰度；页面继续保留来源链接。原有58张图标及其灰度文件、130条映射和九职业规则数据均保持原样。

13项相关测试及24项实际Chrome检查通过，覆盖图像解码、第四层加点、减点、模板回载和重置。首次浏览检查的模板地址拼接漏了问号，修正检查脚本后重试通过，产品文件未因此改动。新导出的逐文件回读和发布结果记录在本轮总账。

可复核的[对应说明](evidence/shaman-talent-correspondence-20261025.json)、[素材验收](evidence/shaman-talent-art-20261025.json)与[新素材包](../artifacts/related-tbc-talent-art-20261025/input-map.json)已整理入库；原始HTTP响应头留在本地。
