## 本地地址兼容修复

已有本地服务对旧 `/info/encyclopedia/index.xml` 地址返回普通 404。该地址在已保存的精确路由表中对应 `index.xml.html`，页面实体也存在，因此属于服务层遗漏，不是内容缺失。

修复采用服务器端的本地跳转，保留查询参数，目标必须是同一项目路径下实际存在的文件。目录地址补齐尾斜线；安全项目路径内的真正缺项使用已有归档 404 页面。路径越界和外部跳转继续拒绝。旧 XML 地址的兼容不依赖 JavaScript，也不改变归档原件。

## 打包方式

新包包含 `site/` 静态文件、来源清单、本地服务器、Windows 启动入口和简短说明。解压后运行 `START_BROWSE.cmd`，需要本机 Python。浏览服务仅绑定回环地址，使用自动分配端口并打开本地浏览器。图片按原字节保存，文件采用 ZIP 无损压缩。

打包前检查新输出路径、预计新增量与磁盘安全空间；完整写入后检查成员集合和解压字节，再将临时包转为正式文件。工作区无固定 14GB 上限，D 盘保留至少 10GB 安全空间。校验细节放在验收记录中，包内说明侧重用途与启动方式。

独立复核要求临时文件独占创建，最终文件使用不覆盖既有目标的发布操作；同名竞争文件不得被覆盖或删除。写包后再次枚举来源目录，文件新增、删除或内容变化均阻止正式包发布。ZIP、摘要和报告分别发布；若后续元数据发布失败，工具报错并保留已验证的 ZIP，不删除竞争者的文件。

## 离线盘点

对 v3 的扫描覆盖 1,013 个 HTML/XML 文件、61 个 CSS 文件及 140,010 处静态引用。113,028 处按精确本地身份解析，26,975 处为已有缺失占位，另有 7 处旧 Flash 安装地址属性。未找到有充分本地来源证据的额外图片配对、路径或大小写修复候选。动态 JavaScript 拼接不在这次静态扫描的覆盖范围内。

缺失占位含 `source` 等上下文参数，24,380 个不同标记对应 2,934 个不同的 `requested` 目标。后者仍包括外部或排除内容，不能直接当作恢复队列的剩余资源数。完整明细无损压缩保存，摘要保留计数、来源摘要与代表记录。

v3 与 v4 的来源记录逐项比较，8,431 项相同，只有 404、socketed items、种族舞蹈和 VISA 首页四项改变，没有增删文件。用同一 Python 3.11.2 解析器重计，两版分别为 140,010 和 140,003 处静态引用，差值恰为 7 个已停用安装属性，缺失占位和 `requested` 数均不变。

v4 全量审计使用 Python 3.12.14，静态引用计数为 139,890，包含 26,889 处缺失占位和 2,889 个 `requested` 目标。跨解释器对照发现，3.12 的 HTMLParser 将 iframe 备用内容作为原始文本，3.11 会继续解析其中的标签，因此少计 113 处引用。对 v3 使用同一 3.12 解析器得到 139,897 处，与 v4 仍只差 7。该计数差异不表示取得了新资源；[解析器对照](../research/local-maintenance-20261014/parser-python311.json)和[3.12 对照](../research/local-maintenance-20261014/parser-python312.json)保留了运行时及代表页面记录。

发现的 7 处 Flash CAB 安装属性分布在 socketed items、VISA 和种族舞蹈页面。浏览派生层将其改为 `data-archive-codebase`，网址作为历史元数据保留；原始页面不改。缺失页提示同时改为简短的归档说明。

## 实际解压检查发现的遗漏

首次候选包为 501,698,187 字节，8,442 个成员。包内容核对及 13 项 HTTP 状态、跳转和字节检查通过；独立浏览时发现种族舞蹈页的侧栏图片由 `document.write` 拼接，完成后的文件名包含 `Player Interaction` 对应的空格。运行时属性转换把带引号地址按无空白的 token 处理，因而漏过该图片，浏览器向项目路径之外的 `/shared/…` 发起请求。

修复发生在公共浏览适配脚本：先完成页面原有表达式，再处理带引号的完整地址；地址中的空格交给 URL 解析，存在精确本地路由时使用实体，否则使用缺失图片说明。静态导出不把表达式片段当作下载地址。冻结来源不改。

首次检查还暴露了检查器的旧 404 文案断言、历史展品标题大小写断言，以及预期 404 日志的归类错误。分别修正检查器，保留首次失败记录；舞蹈页越过项目路径的请求仍作为真实失败处理。最终候选使用新输出路径独立生成和检查。
