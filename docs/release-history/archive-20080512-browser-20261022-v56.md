## 当时的发布说明

以2008年5月12日官网为基准的可浏览历史归档。

本轮补入职业专题标题图、18张天赋连线箭头、3张声望奖励图标和38张因改名或移树而漏配的天赋图标，共60个图片文件。补充素材逐项标注关联来源，保留2008年的天赋数据、说明和加点规则。

已核对Deadmines九张早期原图与十张预览，本地和线上均有保存。50个玩家截图图库的原图与缩略图仍待恢复。

下载ZIP并解压，安装Python 3后，Windows双击 `START_BROWSE.cmd`。macOS/Linux在解压目录运行：

```sh
python3 tools/serve_pages_preview.py --site site --port 0 --open-browser
```
