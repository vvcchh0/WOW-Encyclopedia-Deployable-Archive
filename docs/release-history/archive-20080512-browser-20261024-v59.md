## 当时的发布说明

以2008年5月12日的魔兽世界官方百科快照为基准整理的离线浏览版，处理日期为2026年10月24日。

- 恢复五条2006年TCG壁纸公告的预览，复用公告链接中已保存的壁纸。
- 在三组时光之穴图库中加入八张法语指南缩略图，注明Coolwow2来源。
- 保留原图库的缺图说明；50个玩家截图图库的1,684张原图及缩略图仍待取得。

下载ZIP并解压，安装Python 3后，Windows用户双击`START_BROWSE.cmd`。macOS／Linux用户在解压目录运行`python3 tools/serve_pages_preview.py --site site --port 0 --open-browser`。

网站与离线包版本：v59。来源与剩余缺口见[修复说明](https://github.com/vvcchh0/WOW-Encyclopedia-Deployable-Archive/blob/main/docs/news-and-related-gallery-previews-20261024.md)。
