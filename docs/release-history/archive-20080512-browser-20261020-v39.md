## 当时的发布说明

以 2008-05-12 的 Warcraft Encyclopedia 存档为基准，提供百科与部分早期魔兽官网的在线、离线浏览版。

本次 v39 补回两处旧新闻配图：2004 年商店公告与 2005 年祖尔格拉布影片公告。素材取自本地已有的原站文件，历史索引摘要与图片原始字节一致。2004 年促销条目改为带日期说明的静态展品。

玩家截图图库的原图与缩略图仍有缺口；现有指南预览和大图继续保留。详细进度见仓库 CHANGELOG 与 2026-10-20 工作记录。

下载 ZIP 并解压，Windows 双击 START_BROWSE.cmd；其他系统运行 python3 tools/serve_pages_preview.py --site site --port 0 --open-browser。
