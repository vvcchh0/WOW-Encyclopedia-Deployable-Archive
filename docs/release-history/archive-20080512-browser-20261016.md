## 当时的发布说明

以 2008-05-12 的官方百科快照为基准，保存百科及部分早期魔兽官网。

本版包含 2007 年 8 月的五十条新闻及全部二十七张配图，并补回其他新闻与页面素材。情人节、春节和 World PvP 提供三十二张指南大图；六个玩家图库展示二十二张已有指南预览。原玩家截图图库的完整图片仍待恢复。

下载 ZIP（约 510 MB，解压约 575 MB），安装 Python 3。Windows 解压后运行 `START_BROWSE.cmd`；macOS / Linux 运行 `python3 tools/serve_pages_preview.py --site site --port 0 --open-browser`。
