# 2008 年历史归档更新（v57）

修复了情人节指南中 12 处截图显示问题，继续使用归档中已有的原图。该活动的独立投稿图库仍缺 34 张原图和 34 张缩略图。

安装 Python 3，下载并解压 ZIP。Windows 用户双击 `START_BROWSE.cmd`；其他系统可运行 `python tools/serve_pages_preview.py --site site --port 0 --open-browser`。来源与修复说明见仓库的 `docs/`。
