# TBC 天赋图标补充

本轮从 [Vampyr7878 的 TBC 天赋计算器备份](https://github.com/Vampyr7878/WoW-Talent-Caluclator-TBC/tree/2a5f39aadb1c88ded12ff6389f4f0bdc4470c2a4)补入58张图标，覆盖九职业的65项同名天赋。来源版本为2019-10-06；页面将其标为后期关联素材。

## 对应方法

先核对该版本完整Git目录树，再逐项比较九职业XML中的名称、职业和图标引用与2008年天赋数据。65项天赋共享58张图片，形成130条启用／未启用状态的显示映射。原始PNG保留原字节；未启用状态由独立SVG作灰度显示，不生成冒充旧站原图的JPEG。

2008年的天赋名称、说明、等级、位置、前置条件和计算规则保持原样。Mage的Incinerate与Shaman的Improved Fire Nova Totem未满足此次同名对应条件，继续保留缺口；背景、箭头及其他界面素材也未混入此批。

同一来源的十一张箭头／背景候选已于10月23日取得。本轮重新核对完整目录和XML后才扩展到这58张图标，并非首次发现该备份。

## 构建与验收

- v60导出10,331个文件，共632,800,912字节；主代理已完整回读，新增117个文件、修改12个已有文件。
- 58张PNG与58份灰度SVG分开记录；九个职业页面增加来源说明。既有路由、天赋数据与计算逻辑完成逐字节对照。
- v60的九职业加点、减点、重置、模板重载及65项图标对应均通过实际Chrome检查；来源链接的浅底金字对比度不足，未发布该版。
- v61将来源链接改为深蓝色并加下划线，九页均完成显示检查。58张PNG与58份SVG均通过实际浏览器解码及HTTP字节核对。
- 灰度采样覆盖326个像素，透明度均精确保留。最初对读回RGB统一要求误差不超过1阶，三处半透明边缘相差2阶；该失败记录保留。改用相同透明度下合成可见颜色的误差核对后，最大偏差为0.533阶，未修改图片或SVG。此项判据调整和原始读回值单独记录在本地验收中。

v61文件回读已完成，共10,334个文件、717,469,401字节，合入另行说明的BlizzCast现存音频副本。网站与离线包发布仍待合并验收。

来源映射与原字节素材保存在`artifacts/related-tbc-talent-art-20261024/`。详细本地回执在`research/continuous-recovery-20261024/tbc-source-discovery/`和`integration/v60/`，其中原始HTTP记录不公开。

本批只改善天赋页显示，不减少50个美服玩家截图图库的原图或缩略图缺口。
