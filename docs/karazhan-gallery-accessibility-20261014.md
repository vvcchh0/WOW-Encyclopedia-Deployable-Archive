8 个缩略图地址的响应链包含带有 `Memento-Datetime` 的 **2013 年历史 301**，指向 `http://us.battle.net/wow/game/guide/`。这份捕获保存的是官网迁移重定向，没有提供截图图片。部分响应链随后超时，原图地址的历史重定向仍有明确响应头证据。其他只得到时间选择 302 或没有源站响应的地址归入连接失败或重定向未完成。

32 个 404 均取得 Wayback 未存档提示页；这只描述本轮请求结果，没有穷尽其他日期、协议、域名或路径变体。

## 方法与边界

图库页面 `info/dungeons/karazhan-gallery.html` 声明 `numShots = 63`，调用 `addshots`；`new-hp/js/guidegallery-screenie.js` 拼接下列原址：

```text
http://www.worldofwarcraft.com/info/dungeons/images/karazhan/ssN.jpg
http://www.worldofwarcraft.com/info/dungeons/images/karazhan/ssN-thumb.jpg
N = 1..63
```

请求使用 `20080512210044id_` 回放。已取得的三张 `karazhan/thumbs/ssN-thumb.jpg` 预览图不属于这 126 个目标，未混入计数。

先做本轮 direct 连接探测，超时后整批采用现有 `127.0.0.1:7890` 代理，最多两个并发、请求启动间隔至少一秒。TLS 验证保持开启，无全局网络配置变更。初期允许自动跟随重定向；发现历史 301 指向游戏指南后，后段限制跟随一次 Wayback 时间选择重定向，避免继续下载非图片指南页。

初次停批的连续错误计数实现有误，修正后继续未检查地址；响应分类也依据保存的响应头离线更正。首次停批时遗漏的一条已在途结果导致 `ss8.jpg` 后续重复请求一次，最终按原始响应去重，没有将其算成两张截图。后段出现真实连续五次 curl 35 / CONNECT 后 TLS 失败，随后停止全部网络请求。

原始记录合计 **56 次 curl 调用**（55 次目标调用、1 次 direct 探测），观测到 **63 个非 CONNECT HTTP 响应块**。自动重定向会产生额外请求，超时也可能没有响应头，因此 curl 调用数不作为全部 HTTP 请求数。所有保存响应体均尝试图片解码，未找到有效图片。本轮未修改镜像、整合资源或重新打包。
