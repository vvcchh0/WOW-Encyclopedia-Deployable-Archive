## 部署与恢复

在线站点当前为 v61。GitHub 的部署列表保留当前部署和最近两个检查点；更早版本的提交、工作流日志与本地历史导出归档继续保留。

部署记录是发布元数据。重新部署旧版时，使用对应的已验收 Git 提交；无需为每次网页修复重新制作完整包。

发布条件与容量管理见[发布与保留策略](publication-policy.md)，此次数量和体积见[整理记录](github-publication-cleanup-20261025.md)。
