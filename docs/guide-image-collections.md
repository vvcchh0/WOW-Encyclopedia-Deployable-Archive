# 指南图片与玩家图库

本轮目录调查找到了一批仍可取回的历史指南图片。情人节、春节和 World PvP 指南使用父目录中的 `images/ssN.jpg`；玩家图库的脚本则请求另一组地址。World PvP 指南的插图还涉及多个地区，不能仅凭目录相近就归到 Halaa 图库。

采用独立的 **Guide images** 展示区，让这些原图在对应指南和图库入口中可见。图片保留真实捕获日期，点击可打开原尺寸文件；原有图库脚本、截图编号和缺口继续保留。服装模型视图等其他文件可进入素材目录，不作为数字编号截图的替代文件。

展示区只接受三个固定主题及其已保存页面。来源表将每张图片的原始 URL、捕获时间、摘要和长度与主代理来源回执及导出图片记录核对；页面生成只引用已验证的本地对象。早期捕获作为明确的补充来源，保留各自日期。相邻目录、相同编号或有效索引行都不自动创建图库别名。

验收包括来源与引用字面量复核、图片全部帧解码、导出对象核对，以及从页面实际打开图片。原有六组二十二张预览、百科入口、图库分页和历史展品行为继续检查与保留。

来源调查和逐轮进度见[持续恢复记录](continuous-recovery-20261016.md)。指南的七十一项字面量与五十组目录账本已完成[独立复核](../research/continuous-recovery-20261016/publication/root-guide-neighbor-relations-acceptance.json)。
