# 2008 百科离线镜像与官网扩展

用户要求先把既有百科备份搭成可浏览的离线镜像，验证后再沿页面链接获取相近时期的魔兽官网页面，外部社交媒体不追溯。本文件记录本轮范围、重要取舍和验收入口；原始文件和历史压缩包保持不变。

## 第一阶段：可浏览的百科

以 `mirror/20080512/url-map.json` 的 437 个选用实体、52 个核心 HTML 为输入，生成独立的 `offline/site/`。本地服务绑定 `127.0.0.1:8765`，保留原 URL 的路径及查询映射，按保存的 MIME 提供 `.xml` HTML，处理旧式样表声明、绝对链接和共享脚本。派生文件另有来源 SHA-256 与改动清单，不能覆盖原件。

保留原始外观和目录结构。对缺失的菜单展开/收起图片采用可说明的兼容样式恢复功能；文章插图仍显示缺失提示，不能用错误 HTML 或现代图片冒充。晚期菜单 XML 如用于重建，应单列来源和实际日期，不伪称为基准原件。站内未收录页面显示本地说明；页面浏览本身不触发抓取，外部自动资源请求移除或阻止。

验收必须包括 52 个正文路由、首页/词条/分类的实际浏览器渲染、菜单开闭和内部导航、本地资源的 MIME 与失败记录、原始来源不变校验。HTTP 200、可读 HTML 和视觉/交互通过分别记录。浏览器控制组件初始化若失败，应保留错误并使用独立浏览器自动渲染测试，不能用静态检查代替视觉验收。

## 第二阶段：官网扩展

第一阶段通过后才放行网络获取。以百科页面中的真实官网链接和官网首页为种子，在主域 `www.worldofwarcraft.com` 上沿已验证页面继续发现链接和资源。其他官方域名先记录并按用途评估；外部社交媒体不抓取。账号、支付、Armory 等依赖在线服务的功能单列；安装包、大视频和无限查询参数组合不作为普通网页无限展开。

以 `20080512210044` 为中心，优先最近的基准前捕获；先考虑相近 90 日，其他 2008 捕获作为标注的跨日期补充。实际捕获时间、MIME、CDX 摘要、父页面链接、跳转链和内容有效性独立保存。原始错误响应保留为证据，不能通过跟随迁移跳转把现代官网并入 2008 镜像。

工具维护有限批次和可续传的 URL 队列。先验证官网首页与导航第一圈，再据实际规模确定后续批次；不能依据一个空查询宣称页面从未存档，也不能依据下载器成功宣称资源可用。

## 预算与工作分工

完整工作区不超过 14,000,000,000 bytes；D 盘至少保留 10 GiB，另留 256 MiB 写入裕量；普通单实体上限 16 MiB。最多两个 Archive 请求流，连续三次站点失败停止该批次，每批均有请求数和截止时间上限。

根代理负责设计、来源选择、浏览器验收和整合。执行任务分别负责离线构建/服务、最小前端兼容补丁、官网链接发现与有限获取工具，文件所有权隔离。当前工作项及结果记录在 `research/offline-2008/` 和 `research/site-expansion-2008/`，实际结果将在本文件追加，不把计划视为完成。

## 百科构建与实际验收结果

仅百科的初次构建从 437 个有效原件生成 444 个派生路由，其中包含 52 个核心页、兼容资源与本地缺失提示；原来的 13 项错误响应不作为有效资源导入。构建纳入一份 2008-09-14 的有效菜单 XML，作为明确标注的跨日期补充，其余仅晚期素材未混入基准。`offline/build-manifest.json` 记录来源摘要、实际日期、改写理由、未知引用和额外映射载入结果。

兼容层修复旧脚本依赖的样式字符串比较、菜单点击重复触发及搜索框在 DOM 出现前初始化的问题。原件不变；派生脚本的所有 26 个外部脚本与 788 个内联脚本通过 Node 语法检查。5 项服务/构建测试检查本地路由、MIME、路径越界、缺失说明及资源占位等行为。外部遥测被中性化；CSP 与本地链接处理阻止自动外部资源请求。运行时未收录的图片或脚本可收到正确类型的本地占位响应，这种 200 响应不意味着原资源已恢复。

独立 Chrome 155 / Playwright 实际浏览了全部 52 页，验证首页分类跳转、51 项词条菜单、分类展开、鼠标和键盘开闭、正文交叉引用、Elune 精确标题搜索及未支持搜索的本地说明。通过时记录 **0 个外部请求、0 个未捕获脚本错误、0 个资源加载失败**。根代理查看了首页、分类、正文、菜单展开和缺失图片示例截图，确认保留燃烧的远征背景、羊皮纸版面与正文。截图及逐页结果位于 `research/offline-2008/acceptance/`。

初次真实浏览发现字符串改写破坏旧 JS，随后发现内联遥测替换输出了字面反斜杠 n；这些失败记录保留在验收目录。浏览控制插件初始化报系统路径错误，未产生 UI 操作；验收改用本机真实 Chrome 的独立渲染测试。测试等待导航的时序也曾修正，不能把测试上下文销毁误判为页面损坏。

`source-integrity.json` 重新核对了全部 437 个源文件 SHA-256，均未改变；首轮来源索引仍为 `eece186f92e373f10d22f06b475db44fc1076bccfc633b94a691ebedbc4d4a13`。本地服务仅绑定 loopback；启动入口为根目录 `START_OFFLINE.cmd`，备用命令及 Python 要求见 `offline/README.md`。

## 官网扩展首批结果

百科浏览验收通过后，工具从 52 个百科页和 11 个已有导航来源整理出 732 个第一圈唯一 URL，分别记录官网页面、静态资源、其他官方域名及不展开的动态或外部服务。本轮只运行有限首批：20 次精确 CDX 查询，19 次 HTTP 200、1 次读取超时；选中 18 个实体，下载成功 16 个、2 个 gzip 解压失败。16 个成功实体均通过 SHA-256、内容长度、ZIP CRC32 和 CDX SHA1 Base32 校验。空查询、读取超时和解压失败仍是不同状态。详情见 `research/site-expansion-2008/acquisition-report.md`。

其中 14 个页面捕获于 2008-04-02 至 2008-05-12，导入 `offline/source-entities/` 并通过 `offline/approved-expansion-map.json` 纳入统一构建。包括社区、漫画、下载、电影列表、历史新闻、故事入口、PvP 和公会栏目。2007 首页及 2006 入门页仅保存为比较材料，不放入活跃镜像；2008 官网首页、`/index.xml` 与 `/info/index.xml` 的候选别名仍待查。当前根路径 `/` 只是百科入口的本地别名，不能视为已恢复官网首页。

统一构建共 **458 个路由**，原先 437 个选用原件优先，新增 14 个页面；每项保留来源摘要、实际捕获日期和派生摘要。目录 URL 的尾斜杠用于正确解析相对链接；额外页面共享已有的官网样式、脚本和背景。浏览器实际验证 14/14 页正文可读，0 个外部请求、0 个未捕获脚本错误、0 个资源加载失败。捕获的原页面并未因此具有完整素材：未取得的栏目图片和样式仍使用明确的本地占位，逐页记录在 `expansion-browser-validation.json`，实际触发的占位目标另见 `expansion-resource-gaps.json`。

扩展浏览曾发现两个通用改写问题，已修正：旧导航 JS 的裸字符串 `"//"` 应保留为协议分隔符，不能当成网址；`rel="alternate stylesheet"` 应按 token 识别并返回正确 CSS 类型的占位。修复后重建并复测。有限批次结束后没有继续查别名或下载资源；当前成果是可浏览百科和官网扩展试验，官网的图片资源、其他栏目和后续跳转尚未形成完整闭包。

补充交互诊断发现，旧悬浮菜单的 `GoTo()` 和链接默认行为会先后导航到同一本地页面，产生一次取消再成功返回 200；最终目的页正文正常，记录见 `research/offline-2008/compatibility/navigation-diagnostic.json`。正文往返验收明确选择普通链接，避免误点后来生成的同名悬浮菜单链接；这一旧菜单行为保留为已知兼容细节。并行浏览复测曾发生 15 秒加载超时，三个独立静态请求均在 0.04 秒内返回，因此未据此修改服务缓存；最终浏览按顺序进行，每页上限 45 秒，仍等待完整加载。

## 交付与校验

便携包为 `artifacts/WOW_Encyclopedia_20080512_offline_20261011.zip`。解压后运行 `START_OFFLINE.cmd`，需要 Python 3 标准库即可服务；不需要此前的 full_source 包。原件另行保留，重新执行构建则需要完整工作区中的来源资料。

打包程序只接受与当前构建 SHA-256 一致的百科及扩展浏览验收，逐个验证 ZIP 成员摘要和 CRC，并核对四个历史来源包在打包前后均未改变。包内 `FILE_SHA256SUMS.txt`、包外 `.sha256` 和 `artifacts/offline-20261011-package-verification.json` 分别用于文件、压缩包和本次交付的校验。
